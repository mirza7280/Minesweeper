# 💣 Minesweeper Console Game

A console-based Minesweeper game developed using **C++**. This project is part of my Data Structures and Algorithms (DSA) learning journey.

## 📌 About the Project

Minesweeper is a classic puzzle game in which players explore a grid while avoiding hidden mines.

The goal of this project is to build a Minesweeper game using C++ programming concepts and understand how 2D arrays can be used to represent a game board.

## ✨ Current Features

- 9 × 9 game board.
- Board implementation using 2D arrays.
- Separate internal board and display board.
- Board initialization using a constructor.
- Display of row and column numbers.
- Hidden cells represented by `#`.

## 🛠️ Technologies Used

- C++
- 2D Arrays
- Object-Oriented Programming (OOP)
- VS Code
- GCC Compiler

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/mirza7280/Minesweeper.git
```

2. Open the project folder in VS Code.

3. Compile the program:

```bash
g++ board.cpp -o board.exe
```

4. Run the game:

```bash
.\board.exe
```
